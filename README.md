### Objetivo 
El objetivo de esta practica es que el alumno ejercite la teoría acerca del uso y aplicación de las instrucciones condicionales dentro de un programa, así como de la creación y uso de objetos de clases existentes.
### **Practica II**
La practica consta de dos programas
### Fecha.java
La clase Fecha , para crear objetos fecha, así como poder manipular y hacer varias cosas entre ellas.
## compilacion
```bash
javac Fecha.java
java Fecha
```
### SimulacionDeInversion.java
Programa que simula una inversión , el usuario ingresa su monto que quiere invertir así como las fechas del periodo en el que quiere invertir , el programa necesita de la clase Fecha para funcionar, ya que usa algunos de sus métodos. 
## compilacion
```bash
javac SimulacionDeInversion.java
java SimulacionDeInversion
```
